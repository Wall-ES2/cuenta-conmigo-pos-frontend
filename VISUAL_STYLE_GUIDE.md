# Visual style

- Typography: Inter with the operating system UI font as a local fallback. Use clear weight contrast: 400 for body text, 500 to 600 for controls and labels, and 700 for page headings.
- Primary palette: emerald green for primary actions and selected states; slate for text, borders, and neutral surfaces.
- Status colors: red for unavailable or critical stock, amber for warnings, and emerald for healthy stock and success.
- Surfaces: white cards on a pale slate page background, with slate borders and restrained shadows.
- Controls: consistent rounded corners, visible keyboard focus, and comfortable touch targets.
- Consistency: use the existing Tailwind emerald, slate, red, and amber scales plus the POS CSS color tokens in src/index.css for custom CSS.
